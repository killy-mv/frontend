- Web hosting is the service of storing a website's files on a server that stays connected to the internet, so that anyone who requests the site can be served a copy of it. When a browser resolves a domain name to an IP address, that address points at the hosting server, which then responds to the incoming HTTP requests with the site's HTML, CSS, JavaScript, and other assets. Hosting comes in several flavours that trade cost against control: shared hosting puts many sites on one machine, VPS and dedicated servers give you an isolated slice or a whole machine, and cloud platforms scale resources on demand. For frontend work the most common option today is static hosting on a CDN — services like Netlify, Vercel, GitHub Pages, or Cloudflare Pages take your built files and distribute them across edge servers worldwide, so each visitor is served from a location physically near them.
