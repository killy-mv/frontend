Date Formats

Two problems: parsing a string into a Date, and turning a Date back into a string a human wants to read. ISO for the first, Intl for the second.

Input formats

Only the ISO forms are guaranteed by the specification. Anything else is up to the engine — parse it yourself if you cannot control the input.

Output formats built into Date

Locale formatting

toLocaleDateString takes a locale and an options object. This is the right tool for anything a person will read.

Intl.DateTimeFormat

The same engine, but the formatter is reusable — noticeably faster in a loop.
