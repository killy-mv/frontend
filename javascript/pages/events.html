Events

Things that happen to a page: a click, a keystroke, a finished download. JavaScript reacts by running a function you registered — a handler.

Three ways to attach a handler

The event object

The handler receives an event object describing what happened.

Common events

EventFires when
clickan element is clicked
inputa field's value changes, per keystroke
changea field is committed (blur, or select)
submita form is submitted
keydown / keyupa key goes down or comes up
mouseover / mouseoutthe pointer enters or leaves
focus / bluran element gains or loses focus
DOMContentLoadedthe HTML is parsed

Preventing the default action

Many events have a built-in behaviour: a form submits, a link navigates. preventDefault() cancels it.

Removing a handler

removeEventListener needs the same function reference, so an inline arrow cannot be removed. Alternatively pass { once: true }.
