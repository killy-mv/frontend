When to use which

  • freeze — configuration objects, enum-like constants, anything shared that must not drift.
  • seal — an object whose shape is fixed but whose values change; catches typos that would otherwise create a new property.
  • preventExtensions — rarely, when you only want to stop new properties.
None of these give you privacy — the values are still readable. For that, use a closure or a #private class field.
