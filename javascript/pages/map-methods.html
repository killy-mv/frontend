Map Methods

Five methods and one property cover everything a Map does.

set, get, has, delete, clear, size

undefined vs missing

get() returns undefined either way. Use has() when the difference matters.

keys, values, entries

All three return iterators, not arrays. They are live views: change the Map while iterating and the iterator sees it.

Object.groupBy and Map.groupBy

ES2024. Group a list by a computed key in one call — the reduce boilerplate finally got a name.

WeakMap

Keys must be objects, and they are held weakly: when nothing else references the key, the entry disappears. Good for attaching private data to objects.
