Functions

A block of code with a name, written once and run whenever it is called. Functions take arguments and hand back a return value.

Declaring and calling

Return

Execution stops at return. A function with no return gives back undefined.

Parameters and arguments

Parameters are the names in the declaration; arguments are the values passed in. JavaScript does not check how many you pass.

Functions are values

They can be stored in variables, put in arrays, passed to other functions and returned from them. This is what "first class functions" means.

Why bother

Reuse, naming and isolation. Variables declared inside a function are invisible outside it.

Calling a function too early

Function declarations are hoisted, so they can be called from a line above. Function expressions assigned to const cannot.
