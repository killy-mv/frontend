Hoisting

Before running a scope, JavaScript registers every declaration in it. Declarations are known from the start; assignments still happen where you wrote them.

var declarations are hoisted, values are not

let and const are hoisted too — but unusable

They exist from the top of the block, but reading one before its declaration throws. That window is the temporal dead zone.

Function declarations are fully hoisted

Function expressions are not

The classic surprise

Classes are not hoisted usefully

How to never think about it again

  • Use const and let; the TDZ means mistakes throw immediately.
  • Declare variables at the top of the scope that uses them.
  • Do not rely on calling a function before its declaration, even though it works.
  • Enable a linter rule for no-use-before-define.
