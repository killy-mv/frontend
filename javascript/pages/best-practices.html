Best Practices

Habits that make code behave the way it looks like it behaves.

Declare with const, then let

Always use ===

Avoid globals

Give parameters defaults

Do not mutate what you were given

Return early, keep functions small

Name your conditions

Handle errors where you can do something

The short list

  • const by default, === always, no globals.
  • Small functions with honest names; return early.
  • Convert types at the boundary, not in the middle of a calculation.
  • Do not mutate arguments; return new values.
  • Handle errors, or let them propagate — never swallow them.
  • Write the code so the comment is unnecessary; then write the comment about why.
