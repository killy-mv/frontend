BigInt

A separate numeric type for integers of any size. Written with an n suffix, or created with BigInt().

Where Number gives up

Creating one

Arithmetic

All the operators work, but division truncates — there are no fractions.

You cannot mix types

Practical notes

When to reach for it

  • Database ids and Twitter/X-style snowflake ids that exceed 253.
  • Cryptography, hashing, and precise financial totals in the smallest unit.
  • Anywhere you were about to store a large integer in a string to keep it exact.
BigInt is slower than Number and cannot be used with Math. Use it where exactness matters, not everywhere.
