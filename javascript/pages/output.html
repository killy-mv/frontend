Output

JavaScript has no print statement. To show something you write it into the page, pop it up in a dialog, or send it to the developer console.

Writing into an element

The normal way. Find an element, then set innerHTML (parses HTML) or textContent (plain text, always safe).

empty
Rule of thumb: if the text came from a user or a server, use textContent. innerHTML will happily run markup you did not intend to run.

console.log

The developer console (F12) is where output goes during development. It never disturbs the page.

window.alert

alert() blocks everything until the user clicks OK. Useful for a quick check, terrible in a real interface.

document.write

Writes directly into the document stream while it is being parsed. It still works, but calling it after the page has loaded wipes the whole document — which is why nobody uses it any more.

// during parsing: appends here
document.write('hello');

// after load: replaces the entire page
window.onload = () => document.write('goodbye');

Use it only for throwaway experiments.

Returning a value from a function

The cleanest "output" is often no output at all: a function returns a value and the caller decides what to do with it.
