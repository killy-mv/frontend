Web Storage

localStorage and sessionStorage: a synchronous string-to-string map, about 5MB per origin, that never goes to the server.

Storage is keyed by origin. From file:// browsers give each file an opaque origin or block storage entirely, so values may not survive a reload. Serve the folder over http for the full behaviour.
