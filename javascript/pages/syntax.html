Syntax

The rules for how JavaScript is written: what counts as a value, what you may call things, and what the language treats as special.

Two kinds of value

Literals are values written directly in the code. Variables are names that store values.

Identifiers

Names for variables, functions and properties. They must start with a letter, $ or _, and may then contain digits too.

JavaScript is case sensitive

lastName and lastname are two different variables. This is a very common source of "but it's right there!" bugs.

Expressions

An expression is anything that produces a value. Statements are built out of them.
