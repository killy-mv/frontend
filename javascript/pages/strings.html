Strings

Text. Written in single quotes, double quotes or backticks — the three are interchangeable, so pick the one that avoids escaping.

Quotes

Length and indexing

Strings are indexed from zero. length counts UTF-16 code units, which is not always the same as characters.

Escape sequences

CodeMeans
\nnew line
\ttab
\\backslash
\' \"a quote of the enclosing kind
\u00e9a unicode code point

Strings are immutable

Every "modifying" method returns a new string. The original is untouched.
