Variables

A variable is a named container for a value. There are four ways to make one: var, let, const, and — by accident — no keyword at all.

Declaring and assigning

= is the assignment operator, not a claim of equality. Read x = 5 as "put 5 into x".

Declaring several at once

One keyword, commas between the names. Readable when they belong together.

Undeclared variables leak

Assigning to a name that was never declared creates a global variable. Strict mode (and every module) turns this into an error instead.

Types come from the value, not the declaration

JavaScript is dynamically typed. A variable holds whatever you last put in it.

Naming

  • Describe the value, not its type: userCount, not numVar.
  • camelCase for variables and functions.
  • Booleans read like a question: isReady, hasAccess.
  • Short names are fine for short lives — i in a loop, e in a handler.
