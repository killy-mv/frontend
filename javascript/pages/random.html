Random

Math.random() returns a float from 0 (inclusive) to 1 (exclusive). Everything else is built on top of that one number.

The raw output

A whole number in a range

Multiply, floor, and offset. Getting the boundaries right is the whole exercise.

Is it fair? A dice test

Roll enough times and every face should land about the same number of times. This is how you check a range formula is not off by one.

Picking and shuffling

Random strings and ids

Math.random() is not cryptographically secure and must never be used for passwords, tokens or session ids. Use crypto.getRandomValues().

Repeatable randomness

Math.random() cannot be seeded. When you need the same sequence twice — for tests, or a procedurally generated level — write a small generator.
