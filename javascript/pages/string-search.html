String Search

Six ways to ask "is it in there, and where?". Which one you want depends on whether you need a position, a yes/no, or the matched text itself.

indexOf and lastIndexOf

Return the position of a match, or -1 when there is none. That -1 is why includes() exists.

includes, startsWith, endsWith

Plain booleans, and much easier to read.

search

Like indexOf, but takes a regular expression. It cannot take a start position.

match and matchAll

match() returns the first match with its capture groups, or — with the /g flag — every matched string. matchAll() gives you full match objects for every occurrence.
