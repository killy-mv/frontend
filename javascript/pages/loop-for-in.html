For In

Loops over the enumerable string keys of an object — including inherited ones. It is for objects; using it on arrays is a well-known mistake.

Looping over an object

It walks the prototype chain

Anything enumerable inherited from a prototype shows up too. This is why hasOwnProperty guards exist in older code.

Why not on arrays

The keys come back as strings, the order is not guaranteed, and any extra property you attached is included.

The modern replacements

Key order

Integer-like keys come first in ascending numeric order, then string keys in insertion order. Do not rely on it for anything that matters.
