Array Iteration

Methods that run a function once per element. Choose by what you want back: nothing, a same-length array, a shorter array, or a single value.

forEach — do something, return nothing

map — one new value per element

filter — keep the ones that pass

reduce — many values into one

The callback gets an accumulator and the current value, and returns the next accumulator. Always pass a starting value.

flatMap, entries, keys, values

Chaining them

Each method returns an array, so they compose. This is the standard shape of data handling in JavaScript.
