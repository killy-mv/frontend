Operators

Symbols that combine values into a new value. JavaScript has arithmetic, string, comparison, logical, bitwise, assignment and a few one-off operators.

Arithmetic

String operators

+ joins strings. If either side is a string, the other side is converted to one — which is where "12" comes from.

Comparison

Logical

&& and || return one of their operands, not necessarily a boolean, and they short-circuit.

The ternary operator

The only operator taking three operands: condition ? whenTrue : whenFalse.
