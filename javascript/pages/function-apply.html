The argument-count limit

Both apply and spread push every element onto the call stack, so very large arrays throw.

Forwarding arguments

Wrapping a function used to mean apply(this, arguments). Rest and spread now say it more clearly.

Array-like objects

Choosing between them

In new code, prefer spread: fn(...args) for a plain call, fn.call(ctx, ...args) when you also need a this. Reach for apply when you are reading older code, or when the arguments already exist as an array-like that is not iterable.
