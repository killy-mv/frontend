Introduction

JavaScript is the programming language of the web. HTML gives a page its content, CSS gives it a look, and JavaScript gives it behaviour — it can change both of the other two while the page is open.

Every example on this site is a real <script> tag in the page. The dark box shows that script's own source, and the panel underneath shows what it printed when the page loaded. Nothing is faked.

JavaScript can change HTML content

document.getElementById() finds an element, and its innerHTML property is the HTML inside it. Assigning to that property replaces it.

I am the original text.

JavaScript can change styles

Every element has a style object holding its inline CSS. The property names are the CSS names in camelCase: background-color becomes backgroundColor.

JavaScript can change attributes

Attributes written in the HTML — src, href, disabled, hidden — can all be read and written from script.

Most of what a program does has nothing to do with the page. This runs the moment the browser reaches the script tag.

Where it runs

  • In the browser — every browser has a JavaScript engine built in; that is what these pages use.
  • On a server — the same language runs outside the browser under Node.js, Deno or Bun.
  • Elsewhere — mobile apps, desktop apps, databases, build tools.

JavaScript is not Java. The name was a marketing decision in 1995; the languages are unrelated. The official name of the standard is ECMAScript, which is why you see versions called ES6, ES2020 and so on.
