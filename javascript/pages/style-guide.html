Let a tool do it

Hand formatting is wasted effort. Prettier reformats on save; ESLint catches the mistakes that matter. Agree the config once and stop discussing it.

// .prettierrc
{
  "semi": true,
  "singleQuote": true,
  "printWidth": 100,
  "tabWidth": 2
}
The most valuable rules are the ones a formatter cannot apply: no-unused-vars, eqeqeq, no-undef, prefer-const.

File names

  • Lowercase, because some servers are case sensitive and some file systems are not: user-profile.js, never UserProfile.JS.
  • Pick one separator and keep it — kebab-case is the safest.
  • Name the file after its main export.
