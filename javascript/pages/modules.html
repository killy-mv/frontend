Modules

A module is a file with its own scope. Nothing leaks out unless you export it, and nothing comes in unless you import it.

Modules are subject to CORS, so import does not work from a file:// page. The live examples below use dynamic imports of a data URL, which do work; for real files, serve the folder over HTTP (npx serve, python -m http.server).

Loading one

<!-- the type is what makes it a module -->
<script type="module" src="app.js"></script>

// app.js
import { formatPrice } from './money.js';
import money from './money.js';      // the default export
  • Module scripts are deferred automatically — they run after the document parses.
  • They are always in strict mode.
  • Each module is fetched and evaluated once, however many files import it.
  • The path must be a real path: './money.js', not 'money'.

Named exports

// money.js — export at the declaration…
export const VAT = 0.25;
export function formatPrice(n) { return n.toFixed(2) + ' EUR'; }

// …or in one list at the bottom
const rate = 1.1;
export { rate, rate as exchangeRate };

Default exports

// one per module, named by the importer
export default class Logger { }

import Logger from './logger.js';
import AnyNameIWant from './logger.js';   // also fine

// mixing both kinds
import Logger, { LEVELS } from './logger.js';

Named exports are usually the better default: they are explicit at both ends, and they survive renaming and auto-import tooling better.

Import forms

FormBrings in
import { a, b } from './m.js'two named exports
import { a as x } from './m.js'a named export, renamed
import d from './m.js'the default export
import * as m from './m.js'everything, as a namespace object
import './m.js'nothing — just runs it for its side effects
await import('./m.js')loads it lazily, at run time

Dynamic import

A function-like form that returns a promise. Use it for code you only sometimes need — a heavy chart library, an admin panel.

Live bindings

An import is a live view of the exporting module's variable, not a copy taken at import time.
