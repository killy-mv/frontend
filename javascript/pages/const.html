Const

const makes the binding constant, not the value. The name can never be pointed at something else — but if it points at an object, that object is still free to change.

Must be assigned at declaration

Objects assigned to const can change

This is the part that surprises people. The constant is the arrow, not the box it points to.

The same goes for arrays

Really freezing a value

If you want the contents locked too, use Object.freeze().

Block scope, like let

When to use which

  • const by default. If a name never needs to be repointed, saying so removes a whole category of "where did this change?" questions.
  • let for counters, accumulators, and values reassigned in a branch.
  • var essentially never in new code.
A const in a for…of loop head is fine — each iteration creates a new binding. A const in a for (let i = 0; …) head is not, because i++ reassigns it.
