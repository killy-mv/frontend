String Templates

Strings written in backticks. They keep line breaks, and anything inside ${ } is evaluated and dropped into the text.

Interpolation

Any expression fits inside ${ }

Multi-line output

Line breaks and indentation inside the backticks are kept exactly as written.

Building HTML

The most common everyday use: turning data into markup.

Interpolating user input into innerHTML is how injection bugs happen. Escape the values, or build the elements with textContent.

Tagged templates

Putting a function name in front of a template calls that function with the literal parts and the interpolated values separately — which lets you process them.

Raw strings

String.raw ignores escape sequences — handy for Windows paths and regex sources.
