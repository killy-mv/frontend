Writing text safely

If the text above had come from a stranger it could have been <img src=x onerror=…>, and innerHTML would have run it. That is cross-site scripting. textContent cannot do this — it never parses markup.

Attributes vs properties

They are related but not the same object. The attribute is the original HTML; the property is the live value.
