Type Conversion

Explicit conversion is something you write. Coercion is something the engine does for you when an operator meets the wrong type. The rules are learnable.

How objects convert

An object is asked for a primitive: valueOf() first for numeric contexts, toString() for string contexts. You can override both.

Converting user input

Form fields are always strings. Convert once, at the boundary.

Rules worth remembering

  • Convert explicitly at the edges of your program: Number(input.value).
  • Use === so no comparison ever coerces behind your back.
  • + is the only operator that prefers strings.
  • null becomes 0 in arithmetic; undefined becomes NaN.
