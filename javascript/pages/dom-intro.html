The HTML DOM

When a page loads, the browser turns the HTML text into a tree of objects. That tree is the Document Object Model, and JavaScript can read and change every part of it.

The DOM is not HTML

The browser fixes invalid markup while parsing, so the tree you get may not match the text you wrote.

The DOM is not just HTML either

The same node interfaces cover SVG, XML documents, and document fragments. document is one instance of a document — you can create others with DOMParser or document.implementation.
