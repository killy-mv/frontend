Array Const

Declaring an array with const protects the name, not the contents. The array can still grow, shrink and be reordered.

Working without mutation

If you want a value that truly never changes, do not change it — derive a new array instead. Every one of these leaves the original alone.

The habit

  • Declare arrays with const by default — you almost never repoint the name.
  • Use let only when you really do reassign, e.g. list = list.filter(…).
  • Prefer the non-mutating methods when other code holds a reference to the same array.
