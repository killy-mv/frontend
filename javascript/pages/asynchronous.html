Asynchronous JavaScript

JavaScript runs on one thread. "Asynchronous" does not mean parallel — it means queued to run later, once the current work finishes.

Async work is handed to the browser. When it finishes, a callback is queued; the loop runs it only when the stack is empty.

When you really need another thread

Async does not make CPU work faster — it only stops it from blocking waiting. For genuinely heavy computation the browser offers Web Workers, which run on a separate thread and talk to the page by message.
