Iterables

An object is iterable if it has a Symbol.iterator method. That one method is what makes for…of, spread and destructuring work.

What is iterable already

Where iterability is used

The protocol, by hand

An iterator is an object with a next() method returning { value, done }. for…of just calls it repeatedly.

Making your own iterable

Generators do it for you

A function* returns an iterator automatically. yield hands out the next value and pauses until it is asked again.

Iterable vs array-like

Array-like means "has length and numeric keys". The two are independent — Array.from handles both.
