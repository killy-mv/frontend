Array Search

Finding things by value, or by a test you write. The split is: indexOf family compares values, find family runs a function.

By test: find and findIndex

The callback receives (value, index, array) and returns true for a match. Both stop at the first hit.

some and every

Boolean questions about the whole array. Both short-circuit as soon as the answer is decided.
