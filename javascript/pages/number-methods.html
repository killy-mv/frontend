Number Methods

Methods for turning numbers into strings and strings into numbers. Note which ones return a string — toFixed catches people out constantly.

toString

toFixed and toPrecision

Both return strings. toFixed counts decimal places; toPrecision counts significant digits.

parseInt and parseFloat

They read from the start of a string and stop at the first character that does not fit. Number() refuses the whole thing instead.

Number.isInteger and friends

The Number.* versions do not coerce their argument, which is what you almost always want.

Formatting for humans

toLocaleString adds thousands separators, currency symbols and percent signs in the right place for a locale.
