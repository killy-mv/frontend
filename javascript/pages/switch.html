Switch

Compares one value against several cases using strict equality, then runs from the matching case until it hits a break.

The basic shape

break, and what happens without it

Without break, execution falls through into the next case. This is a bug far more often than it is a feature.

Deliberate fallthrough

Stacking cases with no body is the one legitimate use.

Strict comparison

switch uses ===. A string "2" never matches case 2.

switch (true) for ranges

switch only does equality — but if you switch on true, each case can be any boolean expression.

The object-lookup alternative

When every case is a simple mapping, an object is shorter and easier to extend.
