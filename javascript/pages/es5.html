Why it still matters

ES5 is the last version that runs everywhere without a transpiler, so it is still the target for the widest-reach builds and for code that must run in very old environments. Everything from ES6 onwards is built on the foundations laid here — Object.defineProperty in particular is what makes classes, decorators and reactive frameworks possible.
