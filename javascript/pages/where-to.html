Where To

JavaScript lives inside a <script> tag. The tag can hold the code directly, or point at a .js file with the src attribute. Where you put it decides when it runs.

A script in the page

Scripts run in the order the browser meets them, while it is still parsing the HTML. This one runs before the rest of the page below it even exists.

An element that appears later in the document.

Head or body?

Both are legal. A script in <head> runs before the body exists, which is why the classic advice is to put scripts at the end of the body — by then every element is available.

This site uses a plain script in <head> for lesson.js on purpose: the helper it defines must exist before the inline example scripts further down run.

Waiting for the DOM instead

If a script must run early but needs the finished page, listen for DOMContentLoaded.

External scripts

Real projects keep code in separate files. The browser caches them, several pages can share them, and the HTML stays readable.

The markup that loaded them:

<script src="../assets/topics.js"></script>
<script src="../assets/lesson.js"></script>

An external script file contains only JavaScript — no <script> tags inside it. A tag with src ignores any code written between its open and close tags.
