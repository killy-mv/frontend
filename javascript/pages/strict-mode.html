Strict Mode

"use strict" at the top of a file or a function turns a set of silent mistakes into thrown errors. Modules and class bodies are strict automatically.

Turning it on

Undeclared variables

Silent write failures become errors

Duplicate parameters

Reserved words and old syntax

Where it already applies

Is it worth adding?

In new code you rarely type it: if you use modules or classes, you are already in strict mode. It is worth adding to older standalone scripts, where it usually surfaces two or three real bugs immediately.
