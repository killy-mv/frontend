The History API

Change the URL without loading a page. Three calls — pushState, replaceState and the popstate event — are the whole foundation of client-side routing.

The History API needs a real origin. Opened from file:// the pushState examples will report a SecurityError; the hash-based router below works either way. Serve the folder over http to see everything.

The server side

If pushState puts /products/42 in the address bar and the user refreshes, the browser really does request that path. The server must answer with your index.html for any unknown route, or the user gets a 404. This is the "history fallback" setting in every dev server and static host.
