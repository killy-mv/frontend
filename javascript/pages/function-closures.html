Closures

A function remembers the variables that were in scope where it was written — not where it is called. That memory is a closure, and it is how JavaScript does private state.

Where else you have met one

  • Every callback that uses a variable from the surrounding function.
  • Every module — the module body is a scope, and its exports close over it.
  • setTimeout(() => log(name), 100) — name is captured.
  • Getters and setters returned from a factory, as above.
Closures are not a special feature you turn on. Any function that references an outer variable is one; the term just names what already happens.
