Statements

A program is a list of statements. The browser executes them one at a time, in the order they are written.

One instruction per line

A statement is made of values, operators, expressions, keywords and comments. The semicolon ends it.

Semicolons

JavaScript inserts semicolons for you when a line clearly ends — this is automatic semicolon insertion. It usually gets it right, but not always.

Write the semicolons. It costs nothing and removes a whole class of bug.

White space and line length

JavaScript ignores extra spaces and blank lines, so use them for readability. Long statements are usually broken after an operator.

Code blocks

Curly braces group statements so they can be executed together — the body of a function, a loop or an if.
