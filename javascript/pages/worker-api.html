Web Workers

A second thread. It has no DOM, no window and no shared variables — it talks to the page by message only. That restriction is what makes it safe.

A worker is loaded like a script, so the same-origin rule applies. From file:// the examples below fall back to a blob URL, and some browsers block even that. If you see a SecurityError, serve the folder over http.
