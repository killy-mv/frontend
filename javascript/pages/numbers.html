Numbers

JavaScript has one number type: a 64-bit floating point double. There is no separate integer type, which explains most of its arithmetic surprises.

Writing numbers

Precision

A double stores 15–17 significant digits. Beyond that, digits are lost.

Numbers and strings

+ means concatenation if either side is a string; every other arithmetic operator converts to a number first.

Numbers as objects

Never use new Number(). It creates an object that compares by identity.
