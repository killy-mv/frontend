Narrowing a bug down

A checklist

  1. Read the error message and the top line of the stack. It is usually literally true.
  2. Log the inputs, not the outputs — the wrong answer starts as the wrong input.
  3. Cut the problem in half: comment out a chunk, see if the bug survives.
  4. Check the obvious: is the script even loading? Is the element there yet?
  5. Reproduce it in the console with the smallest possible input.
